# Modular-home landing page prototype

A self-contained, responsive landing-page prototype for a modular-home brand.

The entire demo lives in `index.html`: layout, styling, interactions, and embedded imagery. It has no build step and no runtime dependencies.

## Preview locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## What is included

- Full-screen hero and fixed navigation
- Responsive project and feature sections
- Image carousel and scroll-triggered transitions
- Process, call-to-action, and footer sections
- Embedded image assets for a portable single-file demo

## Status

Design prototype only. Buttons and links are placeholders, and the page is not connected to a backend or production content system.
